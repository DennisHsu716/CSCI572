## Concept Directory by Category

### Information Retrieval
- [[Web Search Indexing]] — The process of organizing content for search engine retrieval, involving the extraction of text and metadata from heterogeneous document formats found across the Web. *(Aliases: Indexing, Search Engine Indexing)*

### Digital Preservation
- [[Web Archiving]] — The practice of periodically capturing and storing snapshots of the World Wide Web to ensure long-term access to historical digital content. *(Aliases: Wayback Machine, Internet Archive)*

### Data Representation
- [[Universal Character Encoding]] — Standards and mechanisms used to represent diverse global languages on the web by mapping characters to numerical identifiers. *(Aliases: Unicode, ISO/IEC 10646, UTF-8)*

### Network Theory
- [[Web Graph]] — A mathematical representation of the Web as a collection of nodes (pages) and edges (links) to analyze structure and connectivity. *(Aliases: Linkage, In-degree, Out-degree)*

### Information Architecture
- [[Manual Hierarchical Web Taxonomy]] — A method of organizing web resources into structured, category-based directories often curated by human editors. *(Aliases: Directory, Ontology, DMoZ)*

### Computational Measurement
- [[Data Storage Metrics]] — Standardized units of digital data capacity used to quantify the exponential growth and storage requirements of the internet. *(Aliases: Zettabyte, Exabyte, Petabyte)*

### Web Infrastructure
- [[Web Technology Stack]] — The foundational software infrastructure that serves web content, characterized by varying market dominance and growth rates. *(Aliases: Apache, nginx, Web Server)*

### Data Acquisition
- [[Web Crawler]] — A software component that recursively fetches web pages, parses their content to extract new URLs, and builds the corpus for the search index (p. 20). *(Aliases: Spider, Robot)*

### Data Structures
- [[Inverted Index]] — A core data structure created by the indexer that maps words or tokens to the documents in which they appear, allowing for efficient search retrieval (p. 20). *(Aliases: Index)*

### Search Architecture
- [[Query Processing]] — The process of analyzing and interpreting user search inputs to retrieve and rank relevant documents, involving both front-end normalization and back-end matching (p. 20). *(Aliases: Query Reformulation)*

### Domain Model
- [[User Information Needs]] — The taxonomy of goals that drive a user to perform a web search, typically categorized into informational, navigational, and transactional intents (p. 23). *(Aliases: Search Intent)*

### Network Protocol
- [[Gopher Protocol]] — A TCP/IP application layer protocol designed in the early 1990s for the distribution, search, and retrieval of documents, serving as a functional predecessor to the World Wide Web (p. 3). *(Aliases: Gopher)*

### Business Model
- [[Paid Inclusion Model]] — A search engine monetization strategy where website owners pay a fee to guarantee that their site appears in search results for specific terms (p. 12). *(Aliases: Paid Search)*
- [[Pay-per-click Auction]] — A mechanism introduced by Goto.com that allows advertisers to bid for ad positions, paying only when a user interacts with the link (p. 2). *(Aliases: PPC, Auctioning of positions)*
