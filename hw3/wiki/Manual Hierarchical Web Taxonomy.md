# Manual Hierarchical Web Taxonomy

> [!abstract] Summary
> A method of organizing web resources into structured, category-based directories often curated by human editors.

## Historical Context and Methodology
Before the dominance of automated search, early web navigation was defined by the Manual Hierarchical Web Taxonomy. Services like Yahoo relied on human editors to manually organize web resources into comprehensive categories. The most prominent example, the Open Directory Project (DMoZ), utilized a massive community of volunteer "net-citizens" to build an extensive ontology of the web. 

## Categorization and Distribution
These taxonomies provided a tree-like organization, categorizing everything from high-level topics like "Science" to niche sub-fields like "Computer Science." The data collected by DMoZ was significant enough that it was distributed in the RDF (Resource Description Framework) format, allowing other services to ingest this human-curated metadata. 

While largely superseded by algorithmic [[Web Search Indexing]], these manual taxonomies represent a foundational approach to managing information architecture on the web, prioritizing human-verified classification over the probabilistic ranking seen in modern engines.
