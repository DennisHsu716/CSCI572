# User Information Needs

> [!abstract] Summary
> The taxonomy of goals that drive a user to perform a web search, typically categorized into informational, navigational, and transactional intents (p. 23).

## Taxonomy of Intent
Understanding user goals is essential for effective [[Query Processing]]. Searches are generally categorized by the following primary intentions:

| Intent Type | Description | Proportion (approx.) |
| :--- | :--- | :--- |
| **Informational** | Seeking knowledge on a specific topic | 40% |
| **Navigational** | Intent to reach a specific, known website | 25% |
| **Transactional** | Web-mediated activity (purchasing, downloading) | 35% |

## Search Behavior and Constraints
The manner in which users express these needs is highly dependent on the environment. For example, search behavior is heavily influenced by the technical constraints of the device, such as the limited screen real estate and input mechanisms found in mobile interfaces (p. 22). Adapting to these varied needs requires engines to provide results that are not only relevant but also actionable within the user's current context.

## Related Concepts
* [[Query Processing]]: The mechanism that analyzes the input to align it with specific user information needs.
